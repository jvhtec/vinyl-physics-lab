## Validation and limitations

- Node 22 and npm 10 on dev PC.
- `npm test` includes the cartridge and deterministic geometry/phase tests;
  standard runtime remains dependency-free. `npm run bench` is also available.
- `node test/acceleration-guard.mjs` also covers strict sampled bound
  at 44.1/48/96 kHz; deterministic transients/noise, bit-identical bypass,
  uniform fallback and complex tone phase/THD checks.
- `test/reconstructed-acceleration.mjs` verifies analytic sine
  acceleration, polynomial invariants and an independent 16-phase,
  wider-window check of the 16 kHz cut.
- Chromium browser smoke tested the Lab with the synthetic cut worker,
  live profile/capacitance sync and high-frequency overshoot warning.
  Playwright-core for that local smoke resides **only** in ignored
  `.local-tools/ui-smoke/`, not in dependencies or Git.
- This sparse source checkout intentionally cannot run the full production `npm run build`
  until the original `assets/` and `records/` are downloaded. The default Demo EP can
  be generated in-browser directly when running from an HTTP server.
- No claim of actual measured cartridge output, complete MC mechanics,
  physical cutter safety or equivalence to Neumann hardware. Plugin hosting
  and black-box output measurements are now verified; the original
  hardware characteristics are not.
- **Original cutter issue now bounded in the sampled domain:** 16 kHz
  left-only output was **30,309 m/s²** after upstream de-essing against
  12,000 m/s² target. The new guard gives approximately **11,940 m/s²**
  for the same test, a **−8.091 dB** steady-tone change and under
  **0.001°** measured phase difference. 6 kHz L-only: 14,570 →
  11,940 m/s², −1.729 dB, under 0.001° phase shift. Already-compliant
  1 kHz L=R / 100 Hz L=-R samples are identical to legacy.
- **Important:** sampled central differences underestimate reconstructed
  high-frequency acceleration. At 16 kHz / 48 kHz, ideal sinusoidal
  acceleration can be approximately 1.46× higher than this metric.
  No real cutter safety, thermal, force or continuous-time guarantee is claimed.
  Do not connect this model directly to physical cutting equipment.
